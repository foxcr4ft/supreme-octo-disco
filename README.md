# Supreme Octo-Disco

Projeto de treinamento e integração entre IAs.

## Como funciona
- **Arquiteto (Muse / Meta AI):** Cria e valida as ideias.
- **Executor (outra IA):** Executa apenas o que está em /tasks/.
- **Humano (foxcr4ft):** Aprova tudo.

## Regras
Toda IA DEVE ler o `AGENTS.md` antes de qualquer ação.
Nenhuma IA pode quebrar as regras do AGENTS.md.

## Estrutura
- `/tasks/` - Tarefas validadas para execução
- `AGENTS.md` - Regras obrigatórias
